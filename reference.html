◊ SYNTHOSCOPE REFERENCE ◊

This reference provides a deep dive into every menu and parameter available in the synthesizer. Use the TAB key to switch between menus and the ARROW KEYS to select and modify parameters.

SPACE

Configures the spatial layout of pitches. The TYPE parameter selects the active layout. The MAP parameter determines whether a node's visual POSITION defines its audio frequency, or if its FREQUENCY defines its visual position.

  • LOGARITHMIC: A continuous space where X/Y axes map logarithmically to frequency. Ideal for microtonal exploration and smooth pitch glides.
  • TEMPORAL: A piano-roll view where the X-axis is time and the Y-axis is pitch. Best for traditional sequencing.
  • CARTESIAN: A structured lattice based on the current scale's interval pattern. Excellent for discovering chord shapes and harmonic structures.
  • HEXAGON: An isomorphic hexagonal grid, great for visualizing consistent chord shapes across different keys.
  • TONNETZ: A dynamic triangular grid that reveals triadic and structural relationships within any selected scale.
  • RHYTHM: A circular space for creating polyrhythms. Nodes snap to orbits, where radius determines rhythmic length.
    • Create Orbit: Drag from the center outwards.
    • Resize & Rotate Orbit: Drag an existing orbit line.
    • Delete Orbit: Drag an orbit to the center until it turns red and release.
  • VOID: A blank spatial canvas where gestures and nodes are shown in their original, untransformed state. Useful as a blueprint view.

SCALE

Configure the musical context. TYPE selects the method of scale generation (WESTERN, BINARY, MOS). ROOT sets the key. SNAP quantizes notes to a grid (OFF, SEMITONE, or SCALE). TUNING adjusts the global A4 reference frequency.

PATCH

The patch browser for synth presets, samples, and vocoder settings. Use the TYPE toggle to switch between SYNTH, SAMPLE, and VOCODE mode for the currently selected `EDIT` target. The EDIT target determines which sound is being modified by the synth menus. Set to OFF to browse presets without overwriting, or select a loop (F1) or node (Q) to edit it directly.

CLIP

When in SAMPLE mode, this menu appears. It controls sample playback. TUNE switches between standard resampling (RATE) and GRANULAR synthesis. You can also set the sample LOOP, START, and END points. Granular parameters like GRAIN SIZE and SPEED allow for deep sound mangling.

VOCODER

When in VOCODE mode, this menu appears. It modulates a synthesized carrier signal with the spectral envelope of your microphone input.

WARNING: High risk of audio feedback! Always use headphones (ideally without active noise cancellation) to prevent loud feedback loops when the microphone is active.

Controls include BANDS (spectral resolution), SENSE (input sensitivity), and SYNTH/INPUT/NOISE levels to blend the carrier signal components.

OSC (Oscillator)

The oscillator is the fundamental source of the sound. This menu allows you to mix multiple waveforms. SAW, PULSE, SINE, TRI, SUB, NOISE, and METAL control the volume of each. PWM controls the pulse width, and SRC determines its modulation source.

PITCH

Controls pitch slides and frequency range. SLIDE sets a pitch sweep at the start of a note. TIME is the duration of the sweep. MIN and MAX clamp the note's frequency to a specific range.

FILTER

The filter shapes the timbre by removing frequencies. This menu contains all filter controls, including its dedicated ADSR envelope (ATTACK, DECAY, etc.) and DEPTH, which create sweeps and dynamic changes.

LFO (Low-Frequency Oscillator)

Use an LFO to create rhythmic modulation. RATE is the speed. SHAPE sets the waveform. PITCH, FILTER, and AMP control how much the LFO affects their respective targets.

AMP (Amplifier)

The AMP menu controls the final output stage and volume envelope. LEVEL is the master volume. DRIVE adds saturation. PAN sets the stereo position. The ADSR parameters shape the volume over time: ATTACK, DECAY, SUSTAIN, and RELEASE. SEND controls the amount of signal sent to the FX chain.

FX (Effects)

This menu contains the unified effects chain for the current loop. It includes a CHORUS section (RATE, DEPTH, MIX), a delay section (ECHO, FEEDBACK), and a reverb section (ROOM, DAMP). The final AMOUNT knob is the master wet/dry mix for the entire effects chain.

CONTROL

A special temporal view for recording automation of synth parameters. This allows for creating dynamic, evolving sounds over the course of a loop.

  • TARGET: Selects what the automation will affect (e.g., ALL, LOOP, a specific node Q).
  • X-AXIS & Y-AXIS: Selects which synthesizer parameters to automate.

SETUP

Controls the global visuals and hardware settings.

  • THEME: Changes the color scheme.
  • VISUALS: Selects the background visualization type.
  • SIZE: Adjusts the size/intensity of the background visualization.
  • FADE: Toggles fading trails for moving sounds.
  • LAYOUT, KEYS, OCTAVE: Configure computer keyboard layout and note mapping.
  • LABELS: Toggles the display of note and frequency labels on nodes.
  • PORT: Selects an active MIDI input device.

LOOP

Manage workspaces and tempo. LOOP selects a workspace (F1-F12). LENGTH sets its duration in beats. TEMPO is the global BPM. RECORD sets timing to FREE, DRIVE, or WAIT.

SHARE

Manages saving, loading, and sharing the entire state of your session. All saves are stored locally in your browser.

  • LINK: An action that generates a unique, compressed URL of your current session state and copies it to your clipboard. This link can be shared with others to load an exact copy of your session.
  • NEW: Creates a new save slot with a randomly generated name, duplicating the current state.
  • REMOVE: Deletes the currently loaded save state from your browser's storage. The special DEFAULT state cannot be removed but will be reset to its pristine factory state.
  • STATE: Cycles through all your saved states. Loading a state will completely replace your current session.

PARTY

The PARTY menu enables real-time, collaborative sessions. When you start a party, you become the host and a unique party link is copied to your clipboard. Anyone with the link can join your session.

  • PARTY ID: Displays the unique ID of the current party session. This is read-only.
  • COPY: Copies the party invitation link to your clipboard again.
  • The main PARTY button on the top bar becomes a SCRAM button while in a session. Clicking it will disconnect you from the party. If the host leaves, the party ends for everyone.

Global Controls

These buttons are located in the top-right corner and provide essential global functions.

PANIC Button

The big red PANIC button is an emergency kill-switch. Pressing it will immediately stop all sounding notes, clear all events and nodes from all loops, and reset the synthesizer state. Use with caution!

Record Audio Output (💿 icon)

This button toggles the recording of the main audio output. When you click it, recording starts, and the icon will pulse red. Click it again to stop recording. Your browser will then prompt you to download the complete session as a high-quality .wav file.
