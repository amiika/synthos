◊ SYNTHOSCOPE REFERENCE ◊

This reference provides a deep dive into every menu and parameter available in the synthesizer. Use the TAB key to switch between menus and the ARROW KEYS to select and modify parameters.

SPACE

Configures the spatial layout of pitches. The TYPE parameter selects the active layout, each offering a unique way to visualize and interact with harmony and melody.

  • SPATIAL (LOGARITHMIC): A continuous space where X/Y axes map logarithmically to frequency. Ideal for microtonal exploration and smooth pitch glides.
  • TEMPORAL: A piano-roll view where the X-axis is time and the Y-axis is pitch. Best for traditional sequencing.
  • CARTESIAN: A structured lattice based on the current scale's interval pattern. Excellent for discovering chord shapes and harmonic structures. Includes parameters for AXIS (ON/OFF) and SCALE (SHOW/HIDE) to control visual elements.
  • TUNING: Maps pitch onto a logarithmic spiral, with angle as pitch class and radius as octave. Emphasizes harmonic overtones.
  • HEXAGON: An isomorphic hexagonal grid, great for visualizing consistent chord shapes across different keys.
  • TONNETZ: A dynamic grid that reveals triadic and structural relationships within any selected scale.
  • EDGE: A variation of the Tonnetz that emphasizes the relationships between chord edges.
  • RADAR: A circular timeline where angle represents time and radius represents pitch. Useful for visualizing cyclical patterns.
  • RHYTHM: A circular space for creating polyrhythms. Nodes snap to orbits, where the radius determines the rhythmic length.
    • Create Orbit: Drag from the center outwards.
    • Resize & Rotate Orbit: Drag an existing orbit line.
    • Delete Orbit: Drag an orbit to the center until it turns red.
  • VOID: A blank spatial canvas where gestures and nodes are shown in their original, untransformed state. Useful as a blueprint view.
  • OFF: No grid is displayed, allowing for a clean view of the visualizer.

SCALE

Configure the musical context. TYPE selects the method of scale generation (Western, Binary, MOS, etc.). ROOT sets the key. SNAP quantizes notes to a grid (OFF, SEMITONE, or SCALE).

PATCH

Load preset sounds. GROUP selects a category (LEAD, PAD, BASS, etc.). PATCH browses sounds in that group. RANDOM generates a new sound.

OSC (Oscillator)

The oscillator is the fundamental source of the sound. This menu allows you to mix multiple waveforms. SAW, PULSE, SINE, TRI, SUB, NOISE, and METAL control the volume of each. PWM controls the pulse width, and SRC determines its modulation source.

PITCH

Controls pitch slides and frequency range. SLIDE sets a pitch sweep at the start of a note. TIME is the duration of the sweep. MIN and MAX clamp the note's frequency to a specific range.

AMP (Amplifier)

The AMP menu controls the final output stage and volume envelope. LEVEL is the master volume. DRIVE adds saturation. PAN sets the stereo position. The ADSR parameters shape the volume over time: ATTACK, DECAY, SUSTAIN, and RELEASE.

FILTER

The filter shapes the timbre by removing frequencies. This menu contains all filter controls, including its dedicated ADSR envelope (ATTACK, DECAY, etc.) and DEPTH, which create sweeps and dynamic changes.

LFO (Low-Frequency Oscillator)

Use an LFO to create rhythmic modulation. RATE is the speed. SHAPE sets the waveform. PITCH, FILTER, and AMP control how much the LFO affects their respective targets.

CHORUS (Effects)

This menu contains the unified effects chain. CHORUS controls the chorus modulation. ECHO controls delay time and FEEDBACK. ROOM and DAMP control the reverb. The WET knob is a master mix for the entire chain.

CONTROL

A special temporal view for recording automation of synth parameters. This allows for creating dynamic, evolving sounds over the course of a loop.

  • TARGET: Selects what the automation will affect (e.g., ALL, LOOP, a specific node Q).
  • PARAM: Selects which synthesizer parameter to automate, such as filter cutoff, volume, etc.

SETUP

Controls the visuals. THEME changes the color scheme. SIZE adjusts the waveform visual size. VISUALS selects the visualization type.

LOOP

Manage workspaces and tempo. LOOP selects a workspace (0-9). LENGTH sets its duration in beats. TEMPO is the global BPM. RECORD sets timing to FREE, DRIVE, or WAIT.
