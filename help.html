◊ SYNTHOSCOPE ◊

Experimental xenakian hybrid virtual analog substractive granular synthetizer, live looper, pitch space and scale explorer and a live coding environment inspired by the UPIC as a minimaximalist window to emergent improvised composition and chaotic collaboration

QUICK CONTROLS

  • A-Z + Mouse: Create & Play Notes
  • Click/Drag: Select & Move Nodes
  • Shift + Drag: Marquee Select
  • TAB: Cycle Edit Menus
  • ESC: Close active menus or Stop playback
  • Arrow Keys: Navigate Menus & Change Values
  • ENTER: Apply operation or edit parameter
  • F1-F12: Switch Loops
  • SPACE: Toggle Recording
  • CTRL + Drag: Draw straight/curved gesture (In record mode)
  • §, < or `: Open REPL (Close with ESC)
