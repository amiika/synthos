◊ SYNTHOSCOPE ◊

Experimental xenakian hybrid virtual analog substractive granular synthetizer, live looper, pitch space and scale explorer and a live coding environment inspired by the UPIC as a minimaximalist window to emergent composition and chaotic collaboration

QUICK CONTROLS

  • A-Z: Create & Play Notes
  • Click/Drag: Play or Select & Move Nodes
  • Double Click: Toggle Node Sustain
  • Shift + Drag: Marquee Select
  • TAB: Cycle Spaces
  • ESC: Close active menus or Stop
  • Arrow Keys: Navigate Menus & Change Values
  • ENTER: Apply operation or edit parameter
  • F1-F12: Switch Loops
  • SPACE: Toggle Recording
  • CTRL + Drag: Draw straight/curved gesture (In record mode)
  • CAPSLOCK: Piano mode ON/OFF
  • §, <, ^ or `: Open REPL (Close with ESC)
